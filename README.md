# MP3 Tag Reader and Editor

## 1. Project Introduction
The MP3 Tag Reader and Editor is a C programming project
developed to read, display, and modify metadata information
stored in MP3 audio files.

## 2. Project Objective
- To understand MP3 file structure.
- To learn file handling in C.
- To read and modify MP3 ID3 tags.
- To understand binary file operations.
- To implement metadata editing functionality.

## 3. Technologies Used
- C Programming
- GCC Compiler
- Linux Operating System
- File Handling
- ID3v2 Metadata

## 4. Features
- Read MP3 File Information
- Display MP3 Metadata
- Edit MP3 Tags
- Update Metadata Information

## 5. Concepts Used
- File Handling
- Structures
- Pointers
- Command Line Arguments
- Bitwise Operations
- String Handling
- Binary File Operations

## 6. MP3 Tag Information
The project works with MP3 metadata fields such as:
- Title
- Artist
- Album
- Year
- Genre
- Comment

## 7. File Handling Concepts
- Opening MP3 files in binary mode.
- Reading data from files.
- Writing data into files.
- Modifying existing metadata.
- Closing files.
